## 📚 API 文档

完整的API规范文件位于 docs/api/openapi.yaml，它由FastAPI自动生成，并可在API Gateway启动后实时查看。

- **在线地址**: <http://localhost:8080/docs>

**核心API模块包括**:

- **认证授权**: /auth/login, /auth/refresh

- **智能体管理**: /agents, /agents/{id}/execute

- **知识管理**: /knowledge/search, /knowledge/add

- **工作流管理**: /workflows, /workflows/{id}/run

- **系统管理**: /system/health, /system/metrics
