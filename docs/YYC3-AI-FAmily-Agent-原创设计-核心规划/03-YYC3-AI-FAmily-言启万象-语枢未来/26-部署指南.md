## 🚀 部署指南

### 1. Docker Compose (开发/测试)

这是我们推荐的快速部署方式，适用于开发环境和小规模生产。

1.  \# 启动所有服务

2.  docker-compose up -d

3.  

4.  \# 查看服务状态

5.  docker-compose ps

6.  

7.  \# 查看日志

8.  docker-compose logs -f \[service_name\]

9.  

10. \# 停止所有服务

11. docker-compose down

### 2. Kubernetes (生产)

适用于大规模生产环境的高可用部署。

1.  \# 创建命名空间

2.  kubectl apply -f monitoring/namespace.yaml

3.  

4.  \# 部署数据层

5.  kubectl apply -f monitoring/postgres-deployment.yaml

6.  kubectl apply -f monitoring/redis-deployment.yaml

7.  ...

8.  

9.  \# 部署服务层

10. kubectl apply -f services/api-gateway-deployment.yaml

11. ...

12. 

13. \# 检查部署状态

14. kubectl get all -n yyc3-system

详细配置请参考 docs/deployment/kubernetes.md。
