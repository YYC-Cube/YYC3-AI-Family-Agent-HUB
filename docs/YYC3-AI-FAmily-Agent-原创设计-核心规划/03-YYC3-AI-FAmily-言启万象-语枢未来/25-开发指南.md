## 📖 开发指南

### 1. 环境配置

1.  \# 复制环境变量文件

2.  cp .env.example .env

3.  

4.  \# 编辑 .env 文件，填入你的API密钥

5.  \# 如: OPENAI_API_KEY=sk-...

### 2. 后端开发

1.  \# 进入任意服务目录，例如智能体孵化器

2.  cd services/agent-incubator

3.  

4.  \# 创建虚拟环境

5.  python3 -m venv venv

6.  source venv/bin/activate

7.  

8.  \# 安装依赖

9.  pip install -r requirements.txt

10. 

11. \# 运行服务

12. uvicorn main:app --reload --port 8081

### 3. 前端开发

1.  \# 进入Web UI目录

2.  cd web-ui

3.  

4.  \# 安装依赖

5.  npm install

6.  

7.  \# 启动开发服务器

8.  npm run dev

### 4. 代码规范

- **Python**: 遵循 PEP 8，使用 black 格式化代码，mypy 进行类型检查。

- **TypeScript**: 遵循 ESLint 和 Prettier 配置。

- **提交前**: 请确保 make test 和 make lint 通过。
