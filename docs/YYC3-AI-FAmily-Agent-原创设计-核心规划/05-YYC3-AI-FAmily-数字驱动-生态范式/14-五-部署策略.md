## 五、部署策略

### 5.1 环境规划

2.  │ ├── 本地开发环境

3.  │ └── 共享开发集群

4.  │

5.  ├── 测试环境 (Testing)

6.  │ ├── 功能测试环境

7.  │ ├── 集成测试环境

8.  │ └── 性能测试环境

9.  │

10. ├── 预发布环境 (Staging)

11. │ └── 生产镜像环境

12. │

13. └── 生产环境 (Production)

14. ├── 核心生产集群

15. ├── 边缘节点集群

16. └── 灾备集群

### 5.2 CI/CD流水线

1.  \# GitLab CI/CD 示例配置

2.  stages:

3.  \- build

4.  \- test

5.  \- security-scan

6.  \- deploy-dev

7.  \- integration-test

8.  \- deploy-staging

9.  \- deploy-prod

10. 

11. variables:

12. DOCKER_REGISTRY: "registry.yyc3.ai"

13. DOCKER_DRIVER: overlay2

14. 

15. \# 构建阶段

16. build:

17. stage: build

18. script:

19. \- docker build -t \$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA .

20. \- docker push \$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA

21. only:

22. \- merge_requests

23. \- main

24. 

25. \# 测试阶段

26. test:

27. stage: test

28. script:

29. \- docker run \$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA pytest

30. coverage: '/TOTAL.\*\s+(\d+%)\$/'

31. only:

32. \- merge_requests

33. \- main

34. 

35. \# 安全扫描

36. security-scan:

37. stage: security-scan

38. script:

39. \- docker run --rm -v \$(pwd):/app clair-scanner:latest

40. artifacts:

41. reports:

42. security: security-report.json

43. only:

44. \- merge_requests

45. \- main

46. 

47. \# 部署到开发环境

48. deploy-dev:

49. stage: deploy-dev

50. script:

51. \- kubectl set image deployment/yyc3-dev yyc3=\$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA -n yyc3-dev

52. environment:

53. name: dev

54. url: https://dev.yyc3.ai

55. only:

56. \- main

57. 

58. \# 集成测试

59. integration-test:

60. stage: integration-test

61. script:

62. \- docker run \$DOCKER_REGISTRY/yyc3-test-runner:latest run-integration-tests

63. only:

64. \- main

65. 

66. \# 部署到预发布环境

67. deploy-staging:

68. stage: deploy-staging

69. script:

70. \- kubectl set image deployment/yyc3-staging yyc3=\$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA -n yyc3-staging

71. environment:

72. name: staging

73. url: https://staging.yyc3.ai

74. when: manual

75. only:

76. \- main

77. 

78. \# 部署到生产环境

79. deploy-prod:

80. stage: deploy-prod

81. script:

82. \- kubectl set image deployment/yyc3-prod yyc3=\$DOCKER_REGISTRY/yyc3-core:\$CI_COMMIT_SHA -n yyc3-prod

83. environment:

84. name: production

85. url: https://yyc3.ai

86. when: manual

87. only:

88. \- main
