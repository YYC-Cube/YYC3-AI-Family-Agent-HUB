## 8. 开发与部署指南

### 8.1 开发环境搭建

1.  **克隆代码库**：

<!-- -->

1.  git clone https://github.com/yan-yu-cloud-cube/YYC3-AI-FAmily.git

2.  cd YYC3-AI-FAmily

    1.  **安装依赖**：

<!-- -->

1.  \# Python依赖

2.  pip install -r requirements.txt

3.  

4.  \# 前端依赖

5.  cd frontend && npm install

    1.  **配置环境**：

<!-- -->

1.  \# 复制配置模板

2.  cp config/config.example.yaml config/config.yaml

3.  

4.  \# 根据需要修改配置

5.  vim config/config.yaml

    1.  **启动开发环境**：

<!-- -->

1.  \# 启动后端服务

2.  python -m uvicorn main:app --reload

3.  

4.  \# 启动前端服务

5.  cd frontend && npm run dev

### 8.2 部署指南

1.  **准备基础设施**：

<!-- -->

1.  \# 使用Terraform部署基础设施

2.  cd infra/terraform

3.  terraform init

4.  terraform apply

    1.  **构建镜像**：

<!-- -->

1.  \# 构建应用镜像

2.  docker build -t yyc3/ai-family:latest .

3.  

4.  \# 推送镜像到仓库

5.  docker push yyc3/ai-family:latest

    1.  **部署应用**：

<!-- -->

1.  \# 使用Kubernetes部署

2.  cd deploy/kubernetes

3.  kubectl apply -f namespace.yaml

4.  kubectl apply -f .

    1.  **验证部署**：

<!-- -->

1.  \# 检查部署状态

2.  kubectl get pods -n yyc3

3.  

4.  \# 获取访问地址

5.  kubectl get svc -n yyc3
