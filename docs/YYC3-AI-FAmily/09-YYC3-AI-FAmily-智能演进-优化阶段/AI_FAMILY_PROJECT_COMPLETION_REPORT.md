### 数据流转

```
用户操作
   ↓
页面组件
   ↓
Context / Hooks
   ↓
集成层 (Bridge / Integration)
   ↓
服务层 (Services) / AI 系统层
   ↓
本地存储 (localStorage/IndexedDB)
   ↓
同步队列 (Sync Queue)
   ↓
API 层 (API)
   ↓
Supabase (Remote)
   ↓
数据同步成功 ✅
```
